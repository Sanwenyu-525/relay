# ADR-003：V1 使用同机浏览器工作台

状态：Superseded。日期：2026-09-19。原状态为 Proposed，从未据此宣布实现。用户现已明确 Windows 可安装应用、独立窗口和启动入口，由 [ADR-007](ADR-007-windows-desktop.md) 接续。以下保留当时的背景与取舍，不再指导当前交付。

背景：三套 Workbench 需要共享事实和可测试交互，当前没有原生窗口、系统托盘或跨设备需求。候选为桌面壳+本地后端，或同机浏览器+后端静态分发。

推荐后者，使用 Vue 3/TypeScript/Vite/Router，Pinia 管 UI 状态；后端生产同源分发，开发代理 API。原方案使用 Spring Boot 分发，性能优先调整后后端语言进入 P00 重新评估，不影响浏览器分发方向。减少原生打包与双进程桥接工作，同时保留后端执行和文件能力。依据与具体交互见[工作台设计](../frontend/workbench-design.md)。

代价：本地服务仍需启动，V1 token 仅存在浏览器内存，刷新需重新连接；不提供原生桌面一键登录。若确需桌面壳，另建决策追加启动/凭据交付层，不能借壳绕过 HTTP 领域授权。

影响：前端、启动、身份和打包；不改变业务数据库、Task/Run 和权限 Owner。后续以 P00/P04/P20 实测，版本兼容核验后再锁定。
