## 实施依据与取舍

`/tasks?tab=inbox` 的服务端语义是未归属项目的 `ME/HUMAN` 任务，不能复用为跨项目待处理。新增读取页沿用现有 Review、Task、Run Owner 的投影，不写入第二套状态。Review 与 Task 是不同业务身份，同一任务的 Review 优先显示原请求；受阻 Task 仍独立显示。分组只为阅读，保留各来源的服务端顺序，不设人为紧急期限。Run 请求以四个为一批；页面离开后不启动后续分页或 Run 批次，已在途请求仅忽略返回。

当前 Task 查询已包含验收条件 `target_spec`，原客户端曾丢弃该字段；共享客户端由协调 Agent 同步解析，缺字段时保持 `null`。验收组件不使用当前 CheckPlan 预览冒充实际检查，也不从 Trace 的 hash 匹配推断撤销后的适用性。只有服务端标为当前且验收及产物来源可读的 Completion 凭据可显示当前人工接受；合法的空产物集合不视为来源缺失，存在产物但版本不可用时则不显示当前接受。仍需进入原完成页核对确切对象。
