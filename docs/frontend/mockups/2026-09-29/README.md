## 图像检查与文字校正

已目视检查标题栏、状态差别、禁用原因与恢复入口。Image Gen 仍可能引入文案与布局偏差，开发必须以规范为准：

- 验收图中的“等待相关人员回执/相关人员已回执”应为“等待服务端回执/完成提交已确认”，本项目为单用户，不新增他人审批流程。结果待核对是异常分支；正常明确成功回执直接进入完成。
- 验收依据变化是新的修订，不能把不可变的 v2 内容原地改写。图中的“v2（已变化）”应实现为原依据与当前新修订的对照。
- 接手图异常分支只由真实未确认结果触发；仅调用外部工具不等于 UNKNOWN。图中富文本工具栏不构成新增编辑器功能要求。
- 控件图的“修订说明必填”仅为字段错误示例，不新增保存版本的必填业务条件；当前选用不等于已验收或任务完成。
- 图中文字颜色、hover 明暗、边框与时长不可直接取样作为数值；按 tokens 实现并重新验对比度。各栏是不同时间的状态比较，不是产品中同时出现的四栏页面。
