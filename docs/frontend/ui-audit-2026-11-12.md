## 7. 结论与处置（UI-UNIFY-01）

### P0-1 两套色板：`.pv-page` 与 `/agent` 各有一个绿

`protoPage.css` 自带 23 个 `--pv-*` 变量，改造前有 22 个是写死的十六进制色值；与 `design-tokens.json`
里最近的色 token 平均距离 31.0（redmean）。72 处页面用 `.pv-page`，只有 `/agent` 用 `--relay-*`，
于是「主按钮绿」在全站有两个值（#23704d / #205d47），分隔线也有两个值（#dfe9df / #e8eee8）。

处置：变量名保留为兼容层，值全部改为 `var(--relay-*)`；文件内其余裸色值按显式映射表逐值替换；
新增 `color.border.subtle` 等语义 token 承接原有取值。收敛后该文件裸色值 0 处（注释除外），
由 `scripts/check-ui-conventions.mjs` 持续守住。

### P0-2 三个圆角体系与两套焦点表达

同一文件里出现 7/8/9/10/11/12/13/14px 八种圆角，按钮 9px、输入 8px、卡片 13px；焦点有
两种画法：全局是 inset outline + forest，`.pv-page` 是外扩 3px 浅绿光晕。

处置：按语义收成三档——控件 `radius.control`(8) / 徽标 `radius.badge`(6) / 容器 `radius.panel`(16)；
焦点统一走全局 `:focus-visible`，删掉两处 `box-shadow: 0 0 0 3px` 光晕。

### P0-3 调试入口进了生产包

生产构建产物里能搜到 `/__dev/assist-scenarios` 与实验室标题：导航层写的是
`includeDevTools ? [{ to: "..." }] : []`，判断在运行时，字面量留在包里。

处置：改成构建期常量（`import.meta.env.DEV ? [...] : []`），并把产物串搜写进守卫；
重新构建后 5 个产物文件均无 `__dev` 残留。

### P1-1 错误态在界面上看不出来（已修）

`.field input:not([type="checkbox"])` 这条 (0,2,1) 规则自带 `border` 简写，压掉了
`.field--invalid input` 与 `:is(input)[aria-invalid="true"]` 的 (0,1,1) 红色边框——
用 `FormField` 报错的字段边框仍是中性灰。处置：删除该规则里与全局基座重复的五件套，只留
`width: 100%` 与 `font: inherit`；`uiLab.spec.ts` 有一条断言钉住「错误态边框 = 状态色」。

### P1-2 控件尺寸分档未登记

页面档按钮 34px / 12px 字号，工作台 40-48px / 14px。这不是遗漏而是密度分层，但此前是字面值。
处置：新增 `control.height.page`、`font.size.pageBase`、`font.size.micro`、`layout.page.maxWidth`、
`layout.page.gutter`，把分档写进唯一来源；页面档与工作台档的差异变成可查的 token 差异，
而不是两套复制粘贴。是否把 72 处页面抬到 40px 属于单独验收项，没有随本次色板一起改。

### P1-3 基础组件仍以原生标签直出

扫描到 892 个 `<button>`、184 个 `<input>`、82 个 `<select>`、
41 个 `<textarea>`，其中大量只是拼了 `.primary-button` 这类类名。
处置：建立 `src/ui`（Button / IconButton / FormField / Input / Textarea / Select / Checkbox / Radio /
Switch / Badge / Alert / Spinner / Skeleton，并统一出口 Dialog / EmptyState / PageHeader），
组件输出与既有类名完全一致，因此迁移是「换写法不换像素」。已完成 GoalListView 与 StatusChip 两个试点。

### P1-4 页面级 CSS 仍有存量裸色值

其余 CSS 文件合计 342 处十六进制色值与 67 处 rgb()/hsl()，分布在 76 个文件，
集中在 ActivityView / KnowledgeView / InboxView / ProjectsView 等页面皮肤。
处置：记入 `scripts/ui-conventions-baseline.json` 作为存量基线，守卫阻止新增；逐个页面迁移后再收紧基线。

### P2 其他

- 同一选择器被多个文件重复定义 19 条（如 `.active-filter-chip` 在收件箱与任务列表各写一遍）。
- `.pv-card` 的 13px 圆角、`.pv-stat` 的 12px 圆角已并入 `radius.panel`，但页面内仍有 6 处 17-22px 标题字号
  未建 token：它们属于页面档的字号阶梯（22/17/13/12/11），与工作台档（28/24/16/14/12）按比例对应，
  迁移时随「页面密度档」一起验收，不单独改。
- 中性状态芯片（`status-chip--neutral`）底色是 sidebar 色，在白纸卡片上几乎不可见，属于 P2 可读性问题，
  改动会影响全站所有中性芯片，未在本次批次内调整。
