# 原型视觉对照记录

对象：`conversation-workspace-prototype`（方案 2）。基准图：[会话工作区选定稿](../../docs/frontend/mockups/2026-10-02/conversation-workspace-selected.png)，1721×914。

本文件只记录原型自身的视觉对照结果。功能成绩不记在这里，只看[统一功能验收表](../../docs/testing/overall-acceptance-2026-09-28.md#当前功能验收表)。

## 对照方式

在原型 dev server 上用 Playwright/Chromium 按固定视口截图，与基准图逐项比对布局、密度、间距、可见内容与层级。视口取原型约定的四档：1721×914、1280×720、960×640、390×844。数值仍归[生产 tokens](../../docs/frontend/design-tokens.json)，截图不作为像素真值。

## 结果

| 项 | 结论 |
|---|---|
| 1721×914 整体布局 | 与基准图一致：操作型标题栏、细图标导航、按项目分组的近期任务栏、紧凑任务上下文、宽消息区、独立底部输入器 |
| 近期任务栏 | 一致：`已加载 10 项`、项目分组带任务数、前两个项目直列、其余折叠为「更多项目（2）」 |
| 任务上下文 | 一致：标题与状态同行，长标题单行省略，完整名称经「任务详情」抽屉查看，抽屉不推高页头 |
| 消息区 | 一致：首段完整可见，正文不被输入器遮挡，用户气泡右对齐 |
| 1721 / 1280 / 960 / 390 四档 | 无遮挡、无溢出；中栏收窄时近期任务栏转为浮层，390 宽收起图标栏 |
| 长文本 | 分组名与任务名按宽度省略，不折行 |

## 本轮修正的偏差

1. **会话切换浮层压住消息。** 原实现把「切换会话」`<select>` 绝对定位在页头下方，覆盖消息首段。已移除该浮层，会话切换改入「任务详情」抽屉，默认视图回到基准图。
2. **近期任务栏数据量与稿不符。** 稿为 10 项 / 4 项目 / 「更多项目（2）」，实现原为 4 项且无折叠。已补足示例数据并加折叠行。
3. **工具栏搜索文案与稿不符。** 稿为「搜索资料…」，实现原为「搜索资料与任务」并带 `Ctrl K` 角标。已改为「搜索资料…」；`Ctrl+K` 快捷键仍生效，但不再作为可见提示。
4. **分组名在 1280 折行。** 项目名加省略号，任务数保持完整。

## 未验证

- 未做真实 Windows 窗口、DPI 缩放、输入法组合输入与安装验收；原型不模拟系统窗口控制。
- 未做屏幕阅读器与对比度实测；焦点样式、浮层归还焦点、Enter/Escape 行为只有代码实现，没有运行证据。
- 未做 hover、焦点、冲突、UNKNOWN、权限拒绝、退出保护与失败分支的视觉对照。
- 未接入 API、模型或执行器；所有任务、资料与回复均为内存示例，刷新即清空。
