输入区动效边框原型

独立原型，未接入项目，页面内数据均为演示数据，不代表任何真实运行状态。颜色、间距、圆角、边框宽度取自 docs/frontend/design-tokens.json（v0.3.0 Proposed）。光带宽度 --glow-band: 3px、强度 --glow-strength: 60%、周期 4s / 6s / 7s 均为试验值，未写回 token。规则依据 docs/frontend/workbench-design.md §6.1 与 docs/frontend/design-system.md §7.1。

关闭动效只改变展示，不发送暂停或取消命令，也不隐藏状态文字、查看进度与停止入口。系统开启「减少动态效果」时同样禁用。

三、待验证项（本页无法证明）

  • 光带速度、强度、停止时机是否干扰输入与阅读，需在真实桌面窗口长时间使用判断。
  • Windows WebView 实际缩放与 125%–150% DPI 下的 3px 光带表现。
  • 键盘焦点（focus-visible）与光带并存时的对比度。
  • 屏幕阅读器只应读到状态文字，不应读出装饰光带；阶段变化才播报。
  • 系统「减少动态效果」与本页开关两条路径的表现一致。
  • 切到 Task B 后 Task A 的迟到事件不会让 B 的输入区发光（需接入真实 Run 后验证）。
