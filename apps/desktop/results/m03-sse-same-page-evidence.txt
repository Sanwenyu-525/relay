Test method: start a disposable PostgreSQL 18.6 cluster using the existing
desktop acceptance helper; seed one real Task/Run/Delegate through the
packaged API; hold BUILD_CONTEXT's run_steps row to keep the real Mock Worker
active at event seq 1. Launch the visible packaged Tauri/WebView2 host and
leave the Run page open. Wait for its original SSE HTTP response 200 and two
authoritative Run GETs, showing the first durable hint was consumed.

An admin test session then holds ACCESS EXCLUSIVE on run_events. The frozen
API's next listAfter poll blocks. The test selects exactly one PG backend by
database relay_m02_acceptance, relay_app role, loopback client address,
active Lock wait, SQL shape "select run_id, seq, kind, created_at from
run_events", and pg_blocking_pids containing that one test lock backend.
It captures backend_start and rechecks all predicates in the same SQL call
that issues pg_terminate_backend. No wildcard termination is attempted.
This SQL only locks and ends a disposable connection; it never writes a
domain fact. The failed query makes the existing SSE API destroy its response.
