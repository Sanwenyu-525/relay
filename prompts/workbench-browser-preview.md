## 4. P0：宿主验证与最小工程契约

目标：在实际桌面窗口内嵌入独立网页，证明不会获得工作台权限；这是 P2 硬前置。

1. 根据锁定 Tauri/WebView2 版本核对官方原生容器 API、unstable 需求、profile 隔离与原生生命周期；按复用策略研究成熟机制，不凭最新文档直接升级依赖。
2. 建立只由可信工作台调用的最小容器控制路径：创建、导航、后退/前进、刷新/停止、更新几何、隐藏/销毁、订阅状态；按实际 API 能力定形，不预设泛化 RPC。冻结实例身份、会话作用域、导航代次、错误类型、监听清理和幂等关闭，拒绝迟到请求操作新实例。
3. 验证子 WebView 不因位于 main 窗口继承 IPC capability；隔离工作台 Cookie、LocalStorage、Service Worker 和私有 API token/bootstrap。独立标签名不等于独立 profile。调试态与打包态均验证。
4. 拒绝把工作台主窗口导航到外页；不得通过放宽主窗口 CSP/导航/frame guard、remote capability 通配来实现。拒绝直接访问 Relay API/维护/bootstrap/私有协议，检查别名、IPv6、重定向、弹窗；URL 校验使用解析器，不用字符串前缀充当来源判断。
5. 验证裁切、缩放、焦点、工作台弹窗遮挡、切换会话隐藏与退出销毁。失败定位、修复后重测；不得用另开外部窗口或 iframe 掩盖原生嵌入失败。
6. 冻结新窗口、下载、上传选择、原生权限、证书错误与外部协议策略。推荐首版阻止自动弹窗和下载，提供明确外部打开；摄像头/麦克风/定位/通知默认不授予，证书错误不绕过。未接入文件上传时清楚提示。登录弹窗不兼容可显式转外部浏览器，不承诺迁移登录态。
7. 冻结网页登录态的保留周期与用户清理入口，说明与标签恢复数据的区别；清理不影响工作台登录或业务数据。敏感路径/一次性链接识别不能只靠 query，无法证明可安全保留的完整地址不持久化。

P0 通过后，把选型、候选、取舍、隔离方式、代价与证据记入新的 ADR（编号以当时目录为准），更新浏览器架构所属段落；不把当前推荐候选预写成 Accepted。若新增桌面 IPC，写最小契约及兼容/错误语义；只有确需 HTTP 或数据库变化时才改其主文档并说明 Breaking Change、migration 和回滚风险，默认不新增业务表。

## 5. P1：整合现有右侧工具面板

- 工具入口在普通会话也可打开；无 Project/Task 时网页可用，文件/变更依资格显示，不伪造 ID、不创建占位 Task。
- 文件/产物、变更、网页在同一右栏切换；工作详情有明确入口。Review、停止、待核对与错误提示不被藏死；旧有运行、轨迹和执行输出保留。
- 复用拖宽、收起、响应式和键盘规则。产物深预览与工具不能同时挤出第四列；关闭后焦点回触发入口，标签栏支持键盘导航。
- 文件/产物继续使用原读取与权限，缺目录浏览能力就保留限制；不新增 Shell、Git 写入、文件编辑器或交互终端。
- 样式与数值复用 tokens；确需新数值则在唯一 token 源定义，不复制 CSS 私有常量体系。不开展无关视觉重构。

P1 自检通过不等于网页已交付；P0 尚未通过时不得发布可点击但不可工作的网页功能，并声称首版完成。

## 6. P2：内置人工网页预览

### 6.1 导航与标签

实现多标签新建/切换/关闭、完整 http/https 地址输入、实际 URL 与标题、前进/后退/刷新/停止加载和外部打开。每个标签绑定稳定实例身份与导航代次；浏览器事件是成功/失败事实源，不靠超时伪造成功。空白、加载、失败、停止、进程崩溃均有可操作反馈。

只在用户输入或点击明确入口后导航。Agent 回复中的 URL 仍是候选链接，不自动加载、不把页面隐式加进 Context。不自动调用搜索引擎，不启动开发服务；本地服务没起则解释错误并允许刷新。外部打开先复用已受控的宿主入口；新增时保持可信调用方与协议约束，不拼 Shell 命令。

### 6.2 作用域、恢复与资源

页面关联以 workspace + conversation 隔离，Project/Task 只作来源。切会话释放旧网页实例，保留允许保存的描述；返回由用户重新打开，不恢复表单、请求或网页内部状态。关闭面板仅隐藏当前实例，不暂停 Run；明确区分隐藏、停止加载和销毁。隐藏期间不得弹新窗口或请求权限；同时不得声称网页后台请求已停止。

恢复数据只保留安全描述、顺序和选中项，不存凭据、query、fragment、正文或页面存储；URL path、标题也可能敏感，采用保守规则，不明确安全则不留完整地址。重启只显示待恢复提示，点击且确认当前目标才加载；存储格式有版本、作用域及容量/清理边界，读取损坏或写失败不影响对话和业务回执。无须为最小展示状态新建数据库表。

### 6.3 不变量

首版 Agent 不读取 DOM、不截图、不点击、不填表、不提交内置网页。不向模型暴露新内置页面工具，不扩大 BrowserProvider 权限。人工可浏览网站并操作其表单，但操作有真实副作用；停止加载/关闭不代表撤销请求。页面查看不生成 Verification PASS、Review 批准或 Task 完成。普通网页不是不可变产物，不自动继承旧验收。

## 7. P3：验证、修复与复验

每个缺口都要有“复现/失败检查 → 最小修复 → 同一检查通过”的证据；新行为先定义预期，再写有效测试。不得只提交问题清单，不删除/skip/放宽失败检查换取通过。存量失败先在不回退他人工作前提下确认基线；无关项单列，不扩大修复。
