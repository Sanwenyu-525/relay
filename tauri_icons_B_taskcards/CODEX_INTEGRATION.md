# 将 B · 任务卡片版 接入现有 React + Tauri 项目

本目录为已准备好的图标资源包，使用本包同一套文件。不要重新生成图片、不要换机器人、不要混入另一套图案，不要把 PNG 嵌入 SVG 作为所谓矢量优化。

先确认当前仓库 Tauri 主版本、package.json 脚本、包管理器与实际 src-tauri 路径。下列配置按 Tauri 2 编写；若版本不同，按实际版本迁移字段，不擅自升级框架。

1. 读取 README.zh-CN.md、config/tauri.bundle-icon.fragment.json 和 verification/report.json。
2. 列出当前 bundle.icon、Windows 覆盖配置、运行时 setIcon/set_icon 或窗口创建时 icon 引用。只确认实际来源，不凭截图断言原因。
3. 备份将替换的同名文件，复制本包 src-tauri/icons 内资源，仅合并 bundle.icon 字段。保留已有自定义托盘图标等非本包文件。不修改 identifier、权限、业务逻辑、应用路由或视觉页面。
4. 这套 icon.ico 已含 10 层，顺序为 32、16、20、24、40、48、64、96、128、256。保留首层 32；不无故执行 tauri icon 覆盖已导出的资源，不从小图放大。
5. 仅当项目确实使用 NSIS 且要求安装器/卸载器图标一致时，合并 optional 片段。MSI 项目不要强行加入 NSIS 设置。
6. 运行时存在旧图引用则修正；保留有意设计的动态图标功能。不为本任务新增无必要的 setIcon 代码或权限。
7. 使用项目现有命令构建桌面应用。记录命令、退出码和真实产物路径。不要把仅 Vite 构建成功当成 Tauri 构建成功。
8. 核对应用本体、桌面快捷方式、固定项是否指向同一新版本。在可访问 Windows GUI 时验证实际任务栏；否则明确列为待人工验证。仅在引用链和新构建均正确后考虑旧固定项/缓存；不要自动清理全局缓存。

交付：实际修改文件、实际原因或尚未定位事项、资源校验、执行过的构建结果、待人工验证清单。没有执行的测试不得标记通过。
